# Guía breve de la app de la Panadería

> Para imprimir y dejar a mano. La misma ayuda está dentro de la app: **Más → Ayuda**.

## 1. Instalar la app (una vez por equipo)

Abre la dirección de la app que te dio Felipe y entra con tu cuenta de Google.

- **iPhone o iPad:** en **Safari**, botón **Compartir** (cuadrado con flecha) → **Agregar a inicio**.
- **Android:** en **Chrome**, menú **⋮** → **Instalar aplicación** (o «Agregar a la pantalla principal»).
- **Computador con Windows:** en **Chrome** o **Edge**, el ícono de instalar en la barra de direcciones.

La primera vez, la app pide **acceso**: escribe tu nombre y toca **Pedir acceso**. Un dueño lo aprueba en su teléfono (**Más → Accesos**) y la app se abre sola.

## 2. En la tablet de la panadería

**Pesar un canasto**
1. En **Pesaje**, toca tu nombre (queda elegido hasta que toques **Cambiar**).
2. Toca el pan.
3. Escribe los kilos (o las unidades, si ese pan se cuenta por unidad).
4. Toca **Guardar canasto**.

El pan queda elegido: el siguiente canasto es solo el número y **Guardar**. Si pasa de 20 kg la app avisa, pero se puede guardar igual.

**Plan de hoy:** si los dueños armaron el plan, el botón de cada pan dice cuánto falta (**«faltan 18 kg»**) y más abajo aparece **Plan de hoy** con el plan, las tandas, lo pesado y lo que falta. Desde el 95 % sale en verde, **«✓ cumplido»**; sobre el 110 %, **«sobre el plan»**. Solo informa: se sigue pesando igual.

**Corregir o anular:** en **Pesado hoy**, toca el canasto. La tablet corrige solo lo de **hoy**; lo de días anteriores lo corrigen los dueños.

**Cerrar la entrega:** cuando sale el pedido, **Cerrar entrega** y confirmar. Lo que se pese después va a la entrega siguiente. Si fue un error y la nueva aún no tiene canastos: **Volver a abrir la entrega**.

**Para qué cliente:** si la panadería le vende a más de un cliente, arriba sale **Para:**. Toca el cliente antes de pesar (queda elegido; al principio, el supermercado). Cada cliente tiene su propia entrega: **Cerrar entrega** cierra solo la del cliente elegido. **Ventas sueltas** (alguien que pasa a comprar): elige **Ventas sueltas**, pesa y al guardar escribe **quién compró** (basta el nombre de pila; se puede dejar en blanco). No tiene entregas.

**Sin internet:** sigue pesando. Los canastos dicen **«Por enviar»** y se envían solos al volver la conexión. **No cierres sesión** mientras haya canastos por enviar.

## 3. Para los dueños

| Quiero… | Dónde |
|---|---|
| Ver lo pesado hoy, por pan, entrega y trabajador | **Hoy** (con ‹ › o el calendario, otro día) |
| Armar el plan del día (cuánto hacer de cada pan) | **Hoy** → **Plan del día** → **Armar plan** → **Usar sugerencias** → revisar → **Guardar plan** |
| Armar el plan de mañana | **Hoy** → **Plan de mañana** → **Armar** |
| Agregar algo que no se pesó en la tablet | **Hoy** → el día → **Anotar canasto** |
| Ver el mes y bajar el Excel para la contadora | **Entregas** → **Descargar Excel del mes** |
| Cerrar el mes (desde el día 1 del mes siguiente) | **Entregas** → **Cerrar** (nombre del mes) → confirmar |
| Ver cómo va el mes, el año y las metas | **Números** → **El mes** / **Año y metas** |
| Cambiar un precio | **Más → Catálogo** → el pan → **Cambiar precio** (neto, sin IVA, y desde qué día; con varios clientes, en **Precio por cliente** el de cada uno) |
| Agregar un cliente (almacén, casino…) con su lista de precios | **Más → Catálogo → Clientes e IVA** → **Agregar cliente** → **Copiar los precios de** (opcional) |
| Anotar ventas sueltas | **Más → Catálogo → Clientes e IVA** → **Activar ventas sueltas** y ponles precio; se anotan en la tablet o en **Anotar canasto** |
| Ver lo de un solo cliente | El filtro **Cliente** en **Hoy**, **Entregas**, **Registro** o **Números**; su Excel, en **Entregas** con el filtro o en **Más → Exportar a Excel** |
| Anotar los insumos y su precio de factura (neto) | **Más → Costos y margen → Insumos** → **Agregar insumo** |
| Anotar la receta de un pan (una tanda y lo que sale) | **Más → Catálogo** → el pan → **Anotar receta** |
| Ver el costo y el margen de un pan, o simular otro precio | **Más → Catálogo** → el pan → **Simular precio** |
| Anotar los gastos del mes y ver el resultado | **Más → Costos y margen → El mes** → **Anotar gastos** |
| Anotar los datos de la panadería para los cobros (razón social, RUT, cuenta) | **Más → Cobros → Datos para documentos** (una vez) |
| Anotar los datos de cobro de un cliente (RUT, semanal o mensual, plazo, descuento) | **Más → Catálogo → Clientes e IVA** → el cliente → **Datos de cobro** |
| Cobrarle a un cliente la semana o el mes | **Más → Cobros → Nuevo cobro** (o en la ficha del cliente) → revisar → **Emitir cobro** → **Descargar PDF**, **Compartir** o **Imprimir** |
| Anotar un pago (total o parcial) | **Más → Cobros → Anotar abono**, o en el cobro **Pagar saldo** |
| Ver cuánto debe un cliente | **Más → Cobros** (Por cobrar, Vencido), la ficha del cliente, o **Estado de cuenta** en PDF |
| Mandar precios a un posible cliente | **Más → Cotizaciones → Nueva cotización**; si acepta, **Crear cliente con estos precios** |
| Descargar el respaldo semanal | La franja **Descargar**, o **Más → Exportar a Excel y respaldo** |
| Dar o quitar un acceso (solo dueños) | **Más → Accesos** |

- El **plan** se arma solo para hoy o mañana. La sugerencia es el promedio del mismo día de la semana en las 4 semanas anteriores, redondeado a tandas completas: revísala antes de guardar. Las tandas salen de la receta del pan.
- Con varios clientes, cada uno tiene **su lista de precios** y **sus entregas**. Lo pesado antes de que hubiera varios clientes es del supermercado. El plan, la proyección y las metas son del negocio entero.
- Conviene **cerrar cada mes**: los números quedan fijos y la app trabaja más liviana.
- El **cobro** es un documento interno, **no una factura**: si el cliente pide factura, se hace aparte en el SII y su número se anota en el cobro. Emitir necesita internet. Si después se corrige un canasto de esas fechas, el cobro avisa y se puede **anular y emitir de nuevo**. Un pago de más queda a favor y se descuenta solo del próximo cobro.
- El **respaldo** tiene precios, ventas, costos y cobros: guárdalo en un lugar privado, no lo compartas.
- Si sube un insumo o cambia una receta (por ejemplo, la levadura de verano), anótalo **con la fecha desde la que rige**: los meses anteriores no cambian. El Excel de **Entregas** sale sin costos (es el de la contadora).

## 4. Si algo no funciona

1. Revisa que haya internet y vuelve a abrir la app.
2. Si hay una versión nueva, aparece un aviso arriba; si no: **Más → Buscar actualización → Actualizar ahora**.
3. Si sigue: **Más → Diagnóstico de instalación → Copiar**, y envíaselo a Felipe (con una foto de la pantalla si se puede).

La app no vende ni comparte los datos. El detalle está en **Más → Aviso de privacidad**.
